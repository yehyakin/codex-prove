# v1.2.0 — Sol-first, evidence-bound routing

本页是 v1.2.0 的源码版本说明，不单独证明发布完成。正式状态、最终提交/tag 与该提交的跨平台 CI 链接以 [GitHub Release](https://github.com/yehyakin/codex-prove/releases/tag/v1.2.0) 为准。发布准备的历史门槛与失败记录见[检查表](sol61-release-checklist.md)。

## 变更

- Sol 6.1 承担完整任务和有用协调；Astra 按需提供只读难题咨询；Luna 处理规则明确、可客观验收的机械批量。
- 小任务保持 Direct。Host 身份未知不再自动启动重复协调者；拆分以独立进展是否值得交接成本为依据，不设固定角色配额。
- 明确唯一写入负责人、证据复用、批量代表项检查和外部动作恢复。工作约束不冒充 OS 文件锁、持久 checkpoint、exactly-once 或硬计费上限。
- 开发计量区分 root-only 与全程覆盖，拒绝把重复、冲突、非法、缺失或失败的事件流包装成完整账单；保留已知成功子集及失败历史。
- 同步中英文说明、安装/回滚边界、配图与脱敏三组对照。配图文件里的候选状态属于 2026-10-01 制作档案，不是当前发布状态，也未把预算图重标为实测。

## 验证与限制

冻结运行包为 11 文件，SHA-256 `72d3f417ea4559bf1a5afa71448c79c6f5570b3f43a4ca1e3458909d60c674e0`，与[本次三组对照](../research/2026-10-02-three-arm-results.md)完全相同。发布文字调整不改变运行文件。最新最终 SHA 的测试和 CI 结果记录在 Release，而非借用旧提交的绿色状态。

一个任务、每组一次：三组独立检查均为 19/19，全部没有委派。PROVE 用时 252.253 秒、统一 Standard API 等价估算 $0.1749800；普通 Codex 为 280.917 秒 / $0.2031256，定制 Host 的 da34 组为 230.664 秒 / $0.1739244。因此本例相对普通 Codex 较低/较快，但未胜过选定竞品。不能推导普遍性能、混合模型或订阅节省；82.8% 仍是另一组预算示例。

历史四角色验收包含超时恢复，不是本次小任务自然触发的分工，也不是本版完整路由成功率。Native Nested、物理 Windows、提供方实际费用及普遍 A/B 优势仍不作承诺。

## 安装与恢复

发布后使用完整 Git checkout：先验证源码，再运行对应平台安装器。无 Git 元数据的源码压缩包、运行包片段或审计快照不是直接安装输入。模型可用性取决于账号；安装后重新打开 Codex 会话验证实际角色。

恢复用 `bash scripts/uninstall.sh --restore-latest`，或 PowerShell 的 `scripts/uninstall.ps1 -RestoreLatest`。它只恢复安装器保存的最近一次受管理旧字节；改过的受管理文件会触发拒绝，不覆盖其他 Skill/角色或整份共享配置。具体步骤见 [README](../../README.md#安装)。

## English

This source version makes Sol 6.1 the primary executor and useful coordinator, Astra a scoped read-only adviser, and Luna a rule-based batch worker. Small work stays Direct; no fixed model quota or extra coordinator is required. Accounting, ownership, recovery and evidence limits are explicit. No daemon, global hook or new runtime dependency is introduced; visual-authoring dependencies remain optional.

The single-task case passed 19/19 in every arm with no delegation. PROVE was 13.86% lower in normalized API-equivalent cost and 10.20% shorter in elapsed time than ordinary Codex, but 0.61% higher and 9.36% longer than the host-customized da34 arm. This is not a general, mixed-model or subscription-savings claim. The artwork's October 1 candidate labels and 82.8% illustrative budget remain historical evidence, not current publication status or measured savings.

Use a complete Git checkout and the installers, then reopen Codex to verify model availability. Installer rollback restores the latest managed backup, not arbitrary versions or the user's whole configuration. The [GitHub Release](https://github.com/yehyakin/codex-prove/releases/tag/v1.2.0) records the actual publication, exact commit/tag and CI results.
