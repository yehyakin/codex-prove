# Codex PROVE v1.1.0

2026-09-27 · GPT-6 分工与轻量编排更新。

## 这次改了什么

- Astra 主控、GPT-6 Sol 专项、Terra 常规、GPT-6 Luna Max 批处理。小任务仍然 Direct，不要求四个模型每次全上。
- 有 Host 调用记录就不再空跑身份自证。已授权的本地修复和测试继续进行，不因可恢复的问题反复申请批准。
- 保留单一写入 Owner、依赖分 Wave 和实际产物审核；交接前确认旧执行者已停止。
- 借鉴 Ponytail，优先复用现有实现、标准库和平台能力，不增加常驻 Hook 或运行依赖。
- 加强 macOS、Linux、Windows 安装与回滚检查；更新中英文 README、配图和成本说明。

## 本次真实运行

在隔离的合成项目中，Astra 先规划；Sol 实现带依赖、容量及写路径排斥的调度器，Luna 同时转换数据；两项完成后，Terra 实现依赖这些产物的 CLI；最后同一个 Astra 检查真实文件、完整 Diff、文件哈希和全部测试输出。

- 模式：Desktop **Compatibility / explicit-profile**。四次启动明确选择模型和推理等级，均使用新上下文。旧 Desktop 会话的 custom-role 映射仍是旧版，因此没有把 generic explicit-profile 启动写成 custom-role 选择成功。
- 配置：Astra/high、GPT-6 Sol/high、GPT-5.6 Terra/high、GPT-6 Luna/max。
- 集成：9 项验收和 5 项补充检查，**14/14 通过，exit 0**；Astra 最终结论 **PASS**。
- 范围：三个写入 Owner 不重叠；第二 Wave 等待前置任务通过；预置的未提交用户修改最终字节保持不变。
- 恢复：Sol 发现 Host 编写的验收断言把兄弟路径误判为冲突。Astra 裁决后，Host 修正断言并增加祖先/相等路径检查，原 Sol 重跑通过，未改实现迎合错误测试，也未新增用户审批。
- 运行时修复：Terra 首次命令因旧会话默认目录不存在而失败；补充实际工作目录后，同一 Terra/high 完成任务，没有更换模型或扩大权限。

本轮保留了失败记录和修正前后的 fixture 哈希。这是一个有界 smoke，不是模型质量、速度或节省比例的基准。explicit-profile 的技术权限较宽，按任务边界执行；不能称作 OS 强制只读隔离。最终哈希说明内容保持，不证明过程中绝无临时写入。

macOS 全局安装已通过项目安装器完成。两个 Skill 与四个 Agent 共 11 个源文件逐字节一致，原 config.toml 未改变，旧版本有可恢复备份。

全新 CLI 会话通过名称发现并读取安装后的 Skill，完成一个按钮文案修改，零子代理，结果逐字节验证通过。另一新会话的工具声明发现检查列出四个新角色及正确模型/推理等级；该检查只证明发现，不替代实际角色启动证据。

实际结果与启动记录见 [runtime receipt](v1.1.0-runtime.json)；平台边界见 [运行矩阵](runtime-surface-matrix.md)。Native Nested 和实体 Windows 11 新四模型运行未作为本次已验证能力发布。

## English

GPT-6 Astra controls planning and review, GPT-6 Sol handles bounded specialist work, GPT-5.6 Terra handles regular execution, and GPT-6 Luna Max handles mechanical batches. Small tasks stay Direct. This release reduces identity-only turns and repeated approvals for recoverable, already-authorized local work, while retaining ownership, dependency ordering, and artifact review.

A real four-model Compatibility smoke completed in an isolated synthetic project: two independent workers, a dependent second wave, 14 passing checks, and the same Astra controller's final PASS. The run retained a corrected Host-authored test error and a recovered stale-working-directory failure. Model selection used explicit Host launch parameters, not child self-attestation or a claim of installed custom-role selection.

This bounded run is not a performance or savings benchmark. Native Nested and physical Windows 11 four-model execution remain unverified. Rerun the installer after updating and start a fresh Codex session.
