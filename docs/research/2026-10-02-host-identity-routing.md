# Host 身份可见性与最少有用分工修正

日期：2026-10-02。状态：本地候选；不是上线或降本成绩。

## 已观测问题

一次已结束的隔离实测中，启动记录表明 Host 选择并运行了 Sol 6.1/high，
但它的公开路由说明称自身型号与 effort 不可见，随后额外启动只读 controller，
并将同一检查器的实现与回归交给两个 Sol worker。三个子代理都使用新上下文，
并非直接复制完整父历史。中断前已记录开销就高于单 Host 对照，恢复只是其中一部分。

这里能支持的修正是减少无用的身份回退与协调，不是推断 Luna 必须接手，也不是把
所有成本归到某条提示。原始项目、账户及会话日志保留在私有审计交接包，不收入源码。

## 2026-10-02 核对的官方依据

- [配置优先级](https://learn.chatgpt.com/docs/config-file/config-basic)：普通配置中，
  CLI 选择优先于项目、profile 和用户默认值；用户默认文件不能证明当前会话设置。
- [受管理配置](https://learn.chatgpt.com/docs/enterprise/managed-configuration)：
  管理要求与 legacy managed defaults 有更高约束，因此显式 CLI 选择仍不能冒充
  最终运行回执。保留 requested/selected 与 observed 的区别。
- [Developer settings](https://learn.chatgpt.com/docs/developer-settings)：交互界面可用
  `/status` 看当前模型、`/debug-config` 看配置层；文档没有承诺每个非交互 Host
  都自动获得同样的信息。不为查身份启动新的模型会话。
- [子代理](https://learn.chatgpt.com/docs/agent-configuration/subagents)：配置继承与
  自定义角色选择各有作用域；独立子任务会消耗自己的模型/工具用量。官方建议返回
  提炼结果，并提醒并行写入可能增加冲突与协调开销。

另外核对了本机 `codex exec --help`：支持显式 `--model`、`-c` 和从 stdin 读任务。
这些是启动器可保存、可传递的选择证据，不是模型自行推断身份的依据。

## Adopt / Adapt / Reject

| 决定 | 本轮实现与边界 |
| --- | --- |
| Adopt：区分选择与观测 | 现有可选 probe 从同一组值生成实际 CLI 参数与 Host-only 元数据；观测字段保持 null，不读取凭证或全局默认来猜测。 |
| Adapt：未知身份保留工作能力 | Skill 明确：未知 Host 身份不自动触发 controller；可用 Host 可继续一般 Solo/协调，但不能满足未证实的精确模型或独立审核要求。 |
| Adapt：两份产物不等于两条独立工作流 | 接口未定的实现与紧密耦合测试优先同 owner；真正独立且交接值得的分支仍可并行，Host 可承担其中一支。 |
| Adapt：限制上下文搬运 | 保留 fresh context，传精确路径、相关约束、接口和证据；完整证据仍可查，消息聚焦接口变化、决策、阻塞和完成结果。 |
| Reject：强制更便宜模型或固定配额 | 保持四角色模型/effort 不变；不因为缺少 Luna 就判定失败，不按文件数制造团队。 |
| Reject：把启动选择当执行证明 | 有效当前回执优先，冲突保留；旧会话、子角色配置、自述和用户默认值都不能证明当前 Host。 |
| Reject：另造调度器或自动启用 | 显式调用规则、权限边界、唯一 owner、真实验收保留；不新增 hook、全局配置、角色 ID 或模型调用。 |

## 验证范围

离线测试检查实际命令与传给进程的 Host 元数据相符、Host/child 作用域、观测字段为
unknown、原始与发送提示的字节/哈希、两组上下文对称性，以及原有 opt-in、目录保护和
取消机制。原有安装、源码、角色与基准完整性回归仍需通过。

新增 [14 个前向回归输入及独立判定边界](../../tests/sol61-routing-regressions.md)，
覆盖身份未知/陈旧/冲突、精确模型要求、有价值的并行、显式 controller/独立审核及
证据交接。素材结构检查不等于模型作出了正确决策；本轮不新增付费试验。

已有配图仍锚定其原提交与原引用。若当前入口仅增补本轮路由边界，配图验证可接受
经本轮复核并固定内容哈希的入口版本，同时仍逐条核对原提交与当前引用、维持角色
配置的完整字节校验。不可泛化成允许任意运行时漂移；不重绘或替换已有图片。

是否降低真实总成本/耗时，仍需后续同任务、同权限、同外部验收的隔离配对实测。
两组须获得对称的启动选择信息；结果不能与先前未提供同类上下文的一轮直接作因果对照。
