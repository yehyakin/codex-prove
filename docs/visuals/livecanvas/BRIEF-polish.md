# Selected direction: Routing Atlas

The user selected the first displayed Product Design proposal on 2026-10-01.
Its original Chinese routing poster is retained exactly as the master asset.
Ownership and evidence are new companion topics, not renamed color variants.

## Scope

Add three themes in Chinese and English to the existing LiveCanvas project.
Keep the previous two themes, existing README, SVGs and unrelated media unchanged.
No publishing, Git commit, merge or Photos-library import is included.

## Art direction

Midnight navy, ivory type and fine softly lit orange/mint/violet paths.
Use the selected generated artwork and matching generated raster companions.
Do not replace artwork with custom SVG or CSS drawings.
Text belongs to each poster image. The motion timeline is editable code, while
poster wording is edited through the saved ImageGen prompts or a raster editor.

## Storyboard

Each variant is 1600×900, 30 fps, 180 frames, six seconds. Images use contain
sizing; do not stretch or crop. The cover is frame 156, at 5.2 seconds.

- Routing: retain the headline, candidate label and footnote. Reveal all four
  alternatives together from the task junction toward their labels. Do not show
  the four routes as a required ladder.
- Ownership: reveal both independent scope-owner pairs together. Then reveal
  the handoff line from left to right: stop the old owner and its mutating
  processes, preserve and inspect changes, assign a new owner before writing.
- Evidence: reveal the three real-evidence inputs and their convergence on the
  review result. PASS, FIX and BLOCKED stay a parallel legend, never a sequence.
- From frame 126 onward all art is fully visible and unchanged through frame 179.

Exposure masks only control visibility of the actual source PNG. They are not
substitute artwork, new data, timing measurements or a new user interface.
No CSS animation, wall clock, random motion, zooming text or fabricated metrics.

## Verification

Read source clauses, inspect all six generated poster assets, then render and
inspect key frames and decoded video frames. Compare each full poster with its
cover at the same size. Preserve the source and asset SHA256 hashes in receipts.
Package Live Photos only after rendering: paired metadata, 5.2s still marker,
native local loading and package hashes are separate checks. Phone playback,
wallpaper, Photos import and social upload are not tested or requested.

## Browser scope

The existing loopback gallery remains the preview surface. The available tools
do not include the in-app Browser automation interface. An optional request to
use an independent, logged-out Playwright instance was sent to the user. Do not
run it without that answer; file/frame QA can continue independently.
